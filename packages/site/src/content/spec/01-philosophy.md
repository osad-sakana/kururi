Kururiは、プログラミングの<strong>概念を学ぶこと</strong>に特化した、最初の言語です。書いたコードはPythonに変換されて動きます。ここでは、書き方の細かい決まりの前に、その背景にある考え方を説明します。

## すべては式

Kururiでは、<strong>関数の呼び出しはすべて式</strong>です。式は、評価すると値になります。

```kururi
function main = () {
    print(1 + 2 * 3)
    print(to_int("12") + 1)
}
```

- `1 + 2 * 3`は、評価すると`7`になります。
- `to_int("12") + 1`は、`to_int("12")`が`12`に評価され、`12 + 1`になり、`13`になります。
- `print(...)`も式です。値を返さない関数なので、評価すると`null`になります。

<strong>文は、式を使って「何をするか」を書いたもの</strong>です。プログラムは文の並びで、文の中に文を入れられるものがあります。それがブロックを持つ文です。

## 例外を少なくする

言語の例外は、覚えることを増やします。Kururiは、例外を次の3つに絞っています。

| 例外 | 理由 |
|---|---|
| 代入・宣言・ジャンプは式ではない | `if x = 1`のような書き間違いを、式として通さないため |
| `if` / `while` / `for`は式ではない | 値を返す`if`を持たず、文の書き方を1つに保つため |
| `main`は特別な関数 | プログラムの入口として、引数も戻り値も持たないため |

## 文の4つの種類

| 種類 | 中身 | 例 |
|---|---|---|
| 式文 | 式だけ | `print("a")`、`xs.push(1)` |
| 宣言代入文 | 名前に値を入れる | `var x: int = 1`、`x = 2` |
| ブロック文 | 式とブロック | `if`、`while`、`for` |
| ジャンプ文 | 流れを飛ばす | `return`、`break`、`continue` |

## 間違いは、早く、やさしく伝える

- <strong>型を必ず書く</strong>：変数にも引数にも型を書き、実行する前に型の間違いを見つけます。
- <strong>日本語で案内する</strong>：エラーには、何が起きたかと、どう直すかを書きます。
- <strong>警告を出す</strong>：動くけれど見直したほうがよい書き方（使っていない変数など）は、警告で知らせます。
- <strong>古い書き方を案内する</strong>：以前の書き方や、ほかの言語の癖（`let`、`x++`、`&&`など）を見つけたら、Kururiの書き方を教えます。

## 暗黙のことを減らす

- 条件は<strong>`boolean`だけ</strong>です。`if x`のように、数や文字列を条件にはできません。
- 数と文字列は自動では混ざりません。`to_string`か、文字列補間を使います。
- 自動で変わる型は、`int`から`float`だけです。
- `null`かもしれない値は、型に`?`を付けて、書いたものだけが`null`を持ちます。

## 書き方は1つに

同じことを何通りにも書けると、読むときに迷います。Kururiは、書き方をなるべく1つに決めています。

- 名前の付け方を決めています（変数は`snake_case`、クラスは`UpperCamelCase`、定数は`UPPER_SNAKE_CASE`。`boolean`は`is_`か`has_`で始めます）。
- 繰り返しは`for`と`while`だけです。
- 変数は`var`と`const`だけです。

## 変換後のPythonが読める

変換後のPythonは、できるだけKururiのコードと同じ形にしています。プレイグラウンドでは、Pythonを並べて見られます。ほかの言語へ進むときの橋渡しになるように、という考えからです。

## あえて持たないもの

学ぶ概念を絞るために、次のものは今のところ持っていません。

- クラスの継承
- 例外処理（`try` / `catch`）
- 関数を値として渡すこと（ラムダ、コールバック）
- ジェネリクス
- 辞書（連想配列）
- `switch`、三項演算子、`++` / `--`
- `import`と、複数のファイル
