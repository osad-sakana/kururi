Kururiは、プログラミングの<strong>概念を学ぶこと</strong>に絞った、最初の言語です。書いたコードはPythonに変換されて動きます。細かい書き方の前に、まず背景にある考え方を示します。

## すべては式

Kururiでは、関数の呼び出しはすべて式です。式は、評価すると値になります。

```kururi
function main = () {
    print(1 + 2 * 3)
    print(to_int("12") + 1)
}
```

- `1 + 2 * 3`は、評価すると`7`になる。
- `to_int("12") + 1`は、まず`to_int("12")`が`12`に評価され、`12 + 1`を経て`13`になる。
- `print(...)`も式。値を返さない関数なので、評価すると`null`になる。

文は、式を使って何をするかを書いたものです。プログラムは文の並びで、文の中に文を入れられるものがあります。それがブロックを持つ文です。

## 例外を少なくする

言語に例外が多いほど、覚えることも増えます。Kururiの例外は、次の3つだけです。

| 例外 | 理由 |
|---|---|
| 代入・宣言・ジャンプは式ではない | `if x = 1`のような書き間違いを、式として通さないため |
| `if` / `while` / `for`は式ではない | 値を返す`if`を持たず、文の書き方を1つに保つため |
| `main`は特別な関数 | プログラムの入口なので、引数も戻り値も持たないため |

## 文の4つの種類

| 種類 | 中身 | 例 |
|---|---|---|
| 式文 | 式だけ | `print("a")`、`xs.push(1)` |
| 宣言代入文 | 名前に値を入れる | `var x: int = 1`、`x = 2` |
| ブロック文 | 式とブロック | `if`、`while`、`for` |
| ジャンプ文 | 流れを飛ばす | `return`、`break`、`continue` |

## 間違いは、早く、やさしく伝える

- 変数にも引数にも型を書かせ、実行の前に型の間違いを見つける。
- エラーは日本語で、何が起きたかと、どう直すかを示す。
- 動くけれど見直したほうがよい書き方、たとえば使っていない変数は、警告で知らせる。
- 以前の書き方や、ほかの言語の癖（`let`、`x++`、`&&`など）を見つけたら、Kururiの書き方を教える。

## 暗黙のことを減らす

- 条件に使えるのは`boolean`だけ。`if x`のように、数や文字列を条件にはできない。
- 数と文字列は、自動では混ざらない。`to_string`か文字列補間を使う。
- 自動で変わる型は、`int`から`float`だけ。
- `null`を持てるのは、型に`?`を付けて書いた値だけ。

## 書き方は1つに

同じことを何通りにも書けると、読むときに迷います。Kururiは、書き方をなるべく1つに決めています。

- 名前の付け方は、変数が`snake_case`、クラスが`UpperCamelCase`、定数が`UPPER_SNAKE_CASE`。`boolean`は`is_`か`has_`で始める。
- 繰り返しは`for`と`while`だけ。
- 変数は`var`と`const`だけ。

## 変換後のPythonが読める

変換後のPythonは、できるだけKururiのコードと同じ形にしています。プレイグラウンドでは、Pythonを並べて見られます。ほかの言語へ進むときの橋渡しにするためです。

## あえて持たないもの

学ぶ概念を絞るため、次のものは今のところ持っていません。

- クラスの継承
- 例外処理（`try` / `catch`）
- 関数を値として渡すこと（ラムダ、コールバック）
- ジェネリクス
- 辞書（連想配列）
- `switch`、三項演算子、`++` / `--`
- `import`と、複数のファイル
