Kururiは、実行の前に書き方と型の間違いを見つけて、日本語で案内します。エラーと警告をまとめて診断と呼び、どの診断にも`K`で始まる4桁のコードが付きます。

## コードの体系

上の2桁が種類を表します。

| コード | 種類 | 例 |
|---|---|---|
| `K00xx` | 内部・未対応 | まだ使えない書き方 |
| `K01xx` | 構文 | かっこの閉じ忘れ、古い書き方 |
| `K02xx` | 名前・スコープ | 宣言されていない名前、同じ名前の宣言 |
| `K03xx` | 型 | 型が合わない、`null`かもしれない値 |
| `K04xx` | クラス・アクセス | `private`を外から使った |
| `K05xx` | 予約語・名前の書き方 | 命名規則の違反 |
| `K06xx` | 警告 | 動くけれど、見直したほうがよい書き方 |

エラーが1件でもあると、Pythonへは変換されません。警告だけなら、変換されて動きます。

## 実行時エラー

型の検査では見つけられず、動かして初めて起きるエラーがあります。

| エラー | 起きるとき |
|---|---|
| 位置が配列の長さを超えています | `xs[i]`の`i`が、長さ以上のとき |
| 位置が 0 より小さいので使えません | `xs[i]`の`i`が、負のとき |
| 0 では割れません | `/`、`%`、`div`で0で割ったとき |
| `to_int`・`to_float`の失敗 | 数に直せない文字列を渡したとき |

実行時エラーが起きると、プレイグラウンドはKururiの何行目かも示します。

## よく出るエラー

| コード | 意味 |
|---|---|
| `K0101` | ここに書けないものがあった（文法の誤り） |
| `K0102` | かっこ・引用符などが閉じられていない |
| `K0110` | トップレベルに書けない文を書いた |
| `K0111` | 条件の中に`=`を書いた（比較は`==`） |
| `K0114` | 古い書き方（案内に従って直す） |
| `K0201` | 宣言されていない名前を使った |
| `K0202` | 同じ名前をすでに宣言している |
| `K0204` | `main`関数がない |
| `K0206` | トップレベルの初期値に、`var`の変数を使った |
| `K0211` | 同じ名前を、別の型で宣言した |
| `K0212` | `const`に代入した |
| `K0213` | `for`のループ変数に代入した |
| `K0301` | 型が合わない値を入れた |
| `K0302` | 文字列と数を`+`でつないだ |
| `K0305` | 関数の引数の数が違う |
| `K0306` | 条件や回数などに、使えない型の式を書いた |
| `K0313` | オブジェクトをそのまま表示しようとした |
| `K0315` | 添字に負の数のリテラルを書いた |
| `K0321` | 値を返さない関数で、値を返した |
| `K0322` | 値を返す関数で、`return`しない道がある |
| `K0330` | `null`かもしれない値を、確かめずに使った |
| `K0401` | `private`なものをクラスの外から使った |
| `K0405` | 初期値のないフィールドが、`constructor`で代入されていない |
| `K0501` | 予約語を名前にした |
| `K0502` | Pythonの予約語を名前にした（変換後のPythonが動かなくなるため） |
| `K0506` | 名前の書き方の決まりに合っていない |
| `K0507` | `boolean`の名前が、`is_`・`has_`で始まっていない |

## 警告

警告はプレイグラウンドに表示されます。動くものの、見直したほうがよい書き方です。

| コード | 意味 |
|---|---|
| `K0601` | 使っていない変数 |
| `K0602` | `return`、`break`、`continue`のあとの、実行されない行 |
| `K0603` | 値を使わない式を、文として単独で書いた |
| `K0604` | 値を返さない関数の値を、代入や引数などで使った |
| `K0605` | `while true`の中に、`break`も`return`もない（終わらない） |
| `K0606` | `while`の条件に使っている値が、繰り返しの中で変わらない（終わらないかもしれない） |

## 終わらない繰り返し

無限ループは、コードの形だけでは完全に見つけられません。そこで、見つけやすい2つの形だけを警告します。

```kururi-warning K0605
function main = () {
    while true {
        print("ずっと続く")
    }
}
```

```kururi-warning K0606
function main = () {
    var i: int = 0
    while i < 10 {
        print(i)
    }
}
```

- `K0605`は、`while true`の中に`break`も`return`もないときに出ます。`if`で条件を確かめて、`break`で抜けます。
- `K0606`は、条件に使っている変数が、繰り返しの中のどこでも書き換えられていないときに出ます。`i += 1`の書き忘れが典型です。
- 条件に`input()`や`random`、自作の関数があるときは、警告しません。自作の関数やメソッドを呼んでいて、値が変わるかもしれないときも同じです。判定できない場合は、警告を出さない側に倒しています。
- 警告の出ない無限ループもあります。プレイグラウンドは、実行が10秒を超えると止めます。

## 直し方の案内

どのエラーにも直し方の案内が付きます。一部のエラーは、プレイグラウンドで1クリックで直せます。`let`を`var`に直す、名前の書き方を直す、などです。
