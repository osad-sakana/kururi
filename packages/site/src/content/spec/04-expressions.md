**式**は、評価すると値になるものです。リテラル、変数の名前、演算、関数の呼び出し、配列の添字、フィールドの参照は、どれも式です。

## 評価の仕方

式は、内側から順に評価されて、値に変わります。

```text
1 + 2 * 3
→ 1 + 6        ( 2 * 3 を先に評価 )
→ 7
```

```text
to_int("12") + 1
→ 12 + 1       ( 関数の呼び出しを評価 )
→ 13
```

演算子は、**左から右へ**評価されます。ただし、`and`と`or`は、左を評価して答えが決まれば、右を評価しません（短絡評価）。

```kururi
function noisy = () -> boolean {
    print("評価された")
    return true
}

function main = () {
    print(true or noisy())
    print(false and noisy())
}
```

上のコードでは、`noisy()`は一度も呼ばれません。

## 演算子

優先順位は、上ほど弱く、下ほど強くなります（Pythonに合わせています）。

| 順位 | 演算子 | 意味 |
|---|---|---|
| 1 | `or` | または |
| 2 | `and` | かつ |
| 3 | `not` | でない |
| 4 | `==` `!=` `<` `<=` `>` `>=` | 比較 |
| 5 | `+` `-` | 足し算・引き算（`+`は文字列の連結にも） |
| 6 | `*` `/` `%` | 掛け算・割り算・余り |
| 7 | `-`（前に付ける） | 符号を反転 |
| 8 | `f(x)` `a[i]` `a.b` | 呼び出し・添字・フィールド |

`&&`、`||`、`!`は使えません。`and`、`or`、`not`と書きます。

### 算術

- `+ - *`：両方が`int`なら`int`、どちらかが`float`なら`float`です。
- `/`：<strong>常に`float`</strong>です。`7 / 2`は`3.5`になります。
- `%`：余りです。動きはPythonの`%`と同じで、`-7 % 3`は`2`です。
- 整数の割り算（切り捨て）は、演算子ではなく`div(a, b)`を使います。`div(-7, 2)`は`-4`です。

### 比較

- 比較の結果は`boolean`です。
- `a < b < c`のような連鎖はできません。`a < b and b < c`と書きます。
- `==`と`!=`は、同じ型どうし（`int`と`float`は混ぜられる）と、`null`との比較ができます。配列は、中身で比べます。
- 文字列は、`<`などで辞書順に比べられます。

### 文字列

`+`で文字列をつなげます。文字列と数は、`+`ではつなげません。

```kururi
function main = () {
    var name: string = "Kururi"
    var count: int = 3
    print("こんにちは、" + name)
    print(`${name}は${count}回目です`)
}
```

## 文字列補間

バッククォートで囲んだ文字列の中の`${式}`は、式を評価した値に置き換わります。式の中では、ふつうの式がすべて書けます。バッククォートの中の`{`や`}`は、そのまま文字として書けます。

| エスケープ | 意味 |
|---|---|
| `` \` `` | バッククォート |
| `\$` | `$` |
| `\\` | `\` |
| `\n` `\t` | 改行・タブ |

## 関数の呼び出しは式

関数の呼び出し`f(x)`は、評価すると**戻り値**になります。値を返さない関数（`print`など）の呼び出しは、`null`になります。

```kururi
function double = (n: int) -> int {
    return n * 2
}

function main = () {
    print(double(double(3)))
}
```

内側の`double(3)`が`6`になり、外側の`double(6)`が`12`になって、`print`されます。

## 添字とフィールド

- `a[i]`：配列や文字列の`i`番目（0から数えます）。
- `a.length`：配列や文字列の長さ（`length`はフィールドで、`()`は付けません）。
- `obj.field`：クラスのフィールド。
- `a.method(x)`：メソッドの呼び出し。
