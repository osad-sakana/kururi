<strong>式</strong>は、評価すると値になるものです。リテラル、変数の名前、演算、関数の呼び出し、配列の添字、フィールドの参照が、どれも式になります。

## 評価の仕方

式は内側から順に評価され、値に変わります。

```text
1 + 2 * 3
→ 1 + 6        ( 2 * 3 を先に評価 )
→ 7
```

```text
to_int("12") + 1
→ 12 + 1       ( 関数の呼び出しを評価 )
→ 13
```

演算子は左から右へ評価されます。ただし`and`と`or`は、左を評価した時点で答えが決まれば、右を評価しません。これを短絡評価と呼びます。

```kururi
function is_noisy = () -> boolean {
    print("評価された")
    return true
}

function main = () {
    print(true or is_noisy())
    print(false and is_noisy())
}
```

このコードでは、`is_noisy()`は一度も呼ばれません。

## 演算子

優先順位は、表の上ほど弱く、下ほど強くなります。Pythonに合わせています。

| 順位 | 演算子 | 意味 |
|---|---|---|
| 1 | `or` | または |
| 2 | `and` | かつ |
| 3 | `not` | でない |
| 4 | `==` `!=` `<` `<=` `>` `>=` | 比較 |
| 5 | `+` `-` | 足し算・引き算（`+`は文字列の連結にも） |
| 6 | `*` `/` `%` | 掛け算・割り算・余り |
| 7 | `-`（前に付ける） | 符号を反転 |
| 8 | `f(x)` `a[i]` `a.b` | 呼び出し・添字・フィールド |

`&&`、`||`、`!`は使えません。`and`、`or`、`not`と書きます。

### 算術

- `+`、`-`、`*`は、両方が`int`なら`int`、どちらかが`float`なら`float`になる。
- `/`は常に`float`になる。`7 / 2`は`3.5`。
- `%`は余りで、動きはPythonの`%`と同じ。`-7 % 3`は`2`。
- 整数の割り算（切り捨て）は、演算子ではなく`div(a, b)`で行う。`div(-7, 2)`は`-4`。

### 比較

- 比較の結果は`boolean`。
- `a < b < c`のような連鎖はできない。`a < b and b < c`と書く。
- `==`と`!=`で比べられるのは、同じ型どうしと`null`。`int`と`float`は混ぜてもよい。配列は中身で比べる。
- 文字列は、`<`などで辞書順に比べられる。

### 文字列

文字列は`+`でつなげます。文字列と数は、`+`ではつなげません。

```kururi
function main = () {
    var name: string = "Kururi"
    var count: int = 3
    print("こんにちは、" + name)
    print("${name}は${count}回目です")
}
```

## 文字列補間

文字列`"..."`の中の`${式}`は、式を評価した値に置き換わります。`${ }`の中には、ふつうの式をすべて書けます。文字列を入れ子にすることもできます。

```kururi
function main = () {
    var name: string = "Kururi"
    var xs: int[] = [1, 2]
    print("こんにちは、${name}！")
    print("要素は${xs.length}個で、次は${to_string(xs.length + 1)}個目")
}
```

- 補間が始まるのは、`${`と続けて書いたときだけ。`{`、`}`、`$`は単独なら、そのまま文字として書ける（`"{}"`、`"$100"`）。
- 文字として`${`と書きたいときは、`\$`でエスケープする。`"\${name}"`は、`${name}`とそのまま表示される。
- 値は、`print`や`to_string`と同じ規則で文字列になる。

| エスケープ | 意味 |
|---|---|
| `\"` | `"` |
| `\$` | `$` |
| `\\` | `\` |
| `\n` `\t` | 改行・タブ |

## 関数の呼び出しは式

関数の呼び出し`f(x)`は、評価すると<strong>戻り値</strong>になります。`print`のように値を返さない関数の呼び出しは、`null`になります。

```kururi
function double = (n: int) -> int {
    return n * 2
}

function main = () {
    print(double(double(3)))
}
```

内側の`double(3)`が`6`になり、外側の`double(6)`が`12`になって、`print`で表示されます。

## 添字とフィールド

- `a[i]`は、配列や文字列の`i`番目。0から数える。
- `a.length`は、配列や文字列の長さ。`length`はフィールドなので、`()`は付けない。
- `obj.field`は、クラスのフィールド。
- `a.method(x)`は、メソッドの呼び出し。
