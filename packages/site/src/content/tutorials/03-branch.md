いつも同じ順番で進むだけでは、できることが限られます。**条件**によって、進む道を変えるのが分岐です。

```kururi
function main = () {
    var score: int = 75

    if score >= 90 {
        print("とてもよくできました")
    } else if score >= 60 {
        print("よくできました")
    } else {
        print("もう少しがんばろう")
    }
}
```

## 何が書いてあるか

- `if 条件 { ... }`：条件が成り立つときだけ、`{ }`の中を実行します。
- `else if 条件 { ... }`：前の条件が成り立たなくて、この条件が成り立つとき。
- `else { ... }`：どれも成り立たなかったとき。
- 上から順に調べて、**最初に成り立った1つだけ**を実行します。

## 条件の作り方

- 比べる：`==`（等しい）`!=`（等しくない）`<` `<=` `>` `>=`
- つなぐ：`and`（かつ）`or`（または）`not`（でない）

条件は`boolean`（真か偽）でなければなりません。数を条件にするような曖昧な書き方は、Kururiではエラーにして、理由を教えます。

## 概念：条件は「真か偽」で決まる

どの言語でも、条件は最終的に「真か偽」になります。`if x = 1`のように、比べるつもりで`=`と書く間違いは、よくあるつまずきです。Kururiでは「`==`と書くと比べられます」と教えてくれます。

## ほかの言語では

```python
if score >= 90:
    print("とてもよくできました")
elif score >= 60:
    print("よくできました")
else:
    print("もう少しがんばろう")
```

```typescript
if (score >= 90) {
  console.log("とてもよくできました")
} else if (score >= 60) {
  console.log("よくできました")
} else {
  console.log("もう少しがんばろう")
}
```

## 練習

1. `score`を変えて、3つの結果をすべて出してみましょう。
2. 「60点以上`and` 80点未満」なら「ちょうどよい」と出す分岐を足してみましょう。
