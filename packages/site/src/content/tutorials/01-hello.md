プログラムは、コンピュータにやってほしいことを、**順番に**書いたものです。いちばん小さなプログラムは、画面に文字を出すことです。

```kururi
function main = () {
    print("こんにちは、Kururi！")
}
```

このコードを横のプレイグラウンドに書き写して、**実行**してみましょう。

## 何が書いてあるか

- `function main = () { ... }`は「`main`という名前の手順を作る」という意味です。`{ }`の中に、やってほしいことを上から順に書きます。
- `main`は特別な名前で、プログラムを動かすと**最初に**呼ばれます（入口）。
- `print("...")`は、かっこの中の値を画面に出します。

## 概念：手順は上から順に実行される

`print`を2つ書くと、書いた順に出ます。

```kururi
function main = () {
    print("1 行目")
    print("2 行目")
}
```

「順番に実行される」ことは、ほとんどの言語に共通する、いちばん基本の考え方です。

## ほかの言語では

画面に出す書き方は、言語ごとに違います。考え方は同じです。

```python
print("こんにちは")
```

```typescript
console.log("こんにちは")
```

```java
System.out.println("こんにちは");
```

## 練習

1. 自分の名前を出すプログラムに書き換えてみましょう。
2. わざと`print("こんにちは"`のように、かっこを閉じ忘れて、エラーを読んでみましょう。エラーには、どこが・なぜ・どう直すかが書いてあります。
