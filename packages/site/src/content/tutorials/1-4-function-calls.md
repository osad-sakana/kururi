## なぜ必要か

ここまでの`print`は、決まった言葉しか話せませんでした。くるりんと**会話**するには、こちらの答えを、プログラムが受け取る必要があります。

受け取った答えは、プログラムの中で、**値**として使いたいものです。その値は、計算ではなく、**関数の呼び出し**から返ってきます。

## やってみる

くるりんに名前を聞かれて、答えてみましょう。

```kururi
function main = () {
    print("お名前は？")
    print("こんにちは、" + input() + "さん")
}
```

実行すると、くるりんが名前を聞いて、右側に入力する欄が出ます。名前を入れて Enter を押すと、くるりんが、その名前であいさつします。

## しくみ

`input()`は、キーボードから入力された1行を、文字列として**返す**関数です。呼び出した式は、評価すると、**入力された文字列**になります。

```text
"こんにちは、" + input() + "さん"
→ "こんにちは、" + "さくら" + "さん"   （入力が「さくら」のとき）
→ "こんにちは、さくらさん"
```

このように、関数の呼び出し`f(x)`は、**式**です。評価すると、関数が返す値（**戻り値**）になります。

関数には、2種類あります。

| 種類 | 例 | 呼び出しの値 |
|---|---|---|
| 値を返す関数 | `input()`、`to_int("12")`、`div(7, 2)`、`random(1, 6)` | 戻り値 |
| 値を返さない関数 | `print("...")` | `null`（値がないこと） |

`print`は、くるりんに話させるのが仕事で、値は返しません。そのため、呼び出しを評価すると`null`になります。値を使わないので、普通は、1行の式文として書きます。

## 広げてみる

文字列を、数に変える関数が、`to_int`です。`input()`は、いつも文字列を返すので、計算に使いたいときは、`to_int`で数にします。

```kururi
function main = () {
    print("年齢は？")
    print("来年は、" + to_string(to_int(input()) + 1) + "歳ですね")
}
```

`to_string`は、数を文字列に変えます。文字列と数は、`+`では、そのままつなげません。

ほかにも、便利な関数があります。

```kururi
function main = () {
    print(div(7, 2))
    print(random(1, 6))
}
```

`div(7, 2)`は、7を2で割った、整数の答え（`3`）です。`random(1, 6)`は、1から6までの数を、ランダムに返します。

## わざと間違える

`print`の結果を、そのまま`print`に渡してみましょう。

```kururi-warning K0604
function main = () {
    print(print("こんにちは"))
}
```

くるりんは、「こんにちは」のあとに、「null」と話します。内側の`print`が、値を返さない関数だからです。エラーではありませんが、「値を返しません（nullになります）」という警告が出ます。

## まとめ

- **関数の呼び出しも、式**です。評価すると、**戻り値**になります。
- `input()`は、入力された文字列を返します。
- `print`のように、値を返さない関数の呼び出しは、`null`になります。

## 練習

1. 好きな食べ物を聞いて、くるりんに、「〇〇、おいしいよね」と返させてください。
2. 年齢を聞いて、10年後の年齢を、くるりんに話させてください。
3. `random(1, 6)`で、サイコロを1回ふって、出た目を話させてください。

<details>
<summary>答えの例</summary>

1つ目です。

```kururi
function main = () {
    print("好きな食べ物は？")
    print(input() + "、おいしいよね")
}
```

2つ目です。

```kururi
function main = () {
    print("年齢は？")
    print(to_int(input()) + 10)
}
```

3つ目です。

```kururi
function main = () {
    print("サイコロをふるよ")
    print(random(1, 6))
}
```

</details>
