## なぜ必要か

りんごが1個120円で、3個買うとします。合計をくるりんに話させたいなら、自分で計算して書くこともできます。

```kururi
function main = () {
    print("合計は360円です")
}
```

ただ、値段が変わると書き直しです。計算をコンピューターにやらせれば、値段を変えるだけで済みます。

## やってみる

```kururi
function main = () {
    print(120 * 3)
    print(1 + 2 * 3)
    print((1 + 2) * 3)
}
```

くるりんは、360、7、9と話します。

</div>

## しくみ

`120 * 3`のように、評価すると値になるものを<strong>式</strong>と呼びます。`*`や`+`のような記号は<strong>演算子</strong>です。

式は、内側から順に<strong>評価</strong>されて、最後に1つの<strong>値</strong>になります。`print`は、この値をくるりんに話させます。

<div class="eval" aria-label="1 + 2 * 3 が、1 + 6 を経て、7 になる">
<span>1 + 2 * 3</span><i>→</i><span>1 + 6</span><i>→</i><span>7</span>
<small>2 * 3 を先に評価します。</small>
</div>

<div class="eval" aria-label="(1 + 2) * 3 が、3 * 3 を経て、9 になる">
<span>(1 + 2) * 3</span><i>→</i><span>3 * 3</span><i>→</i><span>9</span>
<small>かっこの中を先に評価します。</small>
</div>

`*`と`/`は、`+`と`-`より先に評価されます。順番を変えたいときは、`( )`で囲みます。

`print(...)`の`( )`の中には、式を書けます。くるりんが話しているのは、式を評価した値です。

## 広げてみる

使える演算子は、次のとおりです。

| 演算子 | 意味 | 例 | 値 |
|---|---|---|---|
| `+` | 足す | `1 + 2` | `3` |
| `-` | 引く | `5 - 2` | `3` |
| `*` | 掛ける | `3 * 4` | `12` |
| `/` | 割る | `7 / 2` | `3.5` |
| `%` | 余り | `7 % 3` | `1` |

`/`は、割り切れなくても小数で答えます。`+`は、文字列をつなぐこともできます。

```kururi
function main = () {
    print(7 / 2)
    print(7 % 3)
    print("くる" + "りん")
}
```

くるりんは、3.5、1、くるりんと話します。

<p class="k">3.5</p>
<p class="k">1</p>
<p class="k">くるりん</p>
</div>

## わざと間違える

式が途中で終わっていたら、評価できません。

```kururi-error K0101
function main = () {
    print(3 * )
}
```

<div class="say">

`*`の右側がからっぽだと、計算できないんだ。ここには、値になるもの、つまり式を入れてね。

</div>

式が必要な場所に`)`があった、と教えてくれます。

## まとめ

<div class="say">

式は、評価すると値になる。これがいちばん大事だよ！

</div>

- 式は、評価すると値になるものです。
- 式は、内側から順に評価されます。`*`と`/`は、`+`と`-`より先です。
- `print`は、式を評価した値を、くるりんに話させます。

## 練習

1. 1個120円のりんごを3個と、50円のかごを買います。合計を、くるりんに話させてください。
2. `10 - 2 * 3`と`(10 - 2) * 3`の値を、実行する前に予想してください。
3. `17 / 5`と`17 % 5`は、どんな値になるでしょう。

<details>
<summary>答えの例</summary>

1つ目です。

```kururi
function main = () {
    print(120 * 3 + 50)
}
```

2つ目は、`10 - 2 * 3`が`4`、`(10 - 2) * 3`が`24`です。

```text
10 - 2 * 3
→ 10 - 6
→ 4
```

3つ目は、`17 / 5`が`3.4`、`17 % 5`が`2`です。

</details>
