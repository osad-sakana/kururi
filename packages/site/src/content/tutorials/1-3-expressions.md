## なぜ必要か

りんごが1個120円で、3個買うとします。合計を、くるりんに話させたいとき、自分で計算して、書くこともできます。

```kururi
function main = () {
    print("合計は360円です")
}
```

でも、値段が変わったら、書き直しです。計算を、**コンピューターにやってもらえたら**、値段を変えるだけで済みます。

## やってみる

```kururi
function main = () {
    print(120 * 3)
    print(1 + 2 * 3)
    print((1 + 2) * 3)
}
```

くるりんは、「360」「7」「9」と話します。

## しくみ

`120 * 3`のように、**評価すると値になるもの**を、**式**と呼びます。`*`や`+`のような記号は、**演算子**です。

式は、内側から順に**評価**されて、最後に1つの**値**になります。`print`は、この値を、くるりんに話させます。

```text
1 + 2 * 3
→ 1 + 6        （2 * 3 を先に評価）
→ 7
```

```text
(1 + 2) * 3
→ 3 * 3        （かっこの中を先に評価）
→ 9
```

`*`と`/`は、`+`と`-`より先に評価されます。順番を変えたいときは、`( )`で囲みます。

`print(...)`の`( )`の中には、式を書けます。くるりんが話しているのは、式を評価した**値**です。

## 広げてみる

使える演算子は、次のとおりです。

| 演算子 | 意味 | 例 | 値 |
|---|---|---|---|
| `+` | 足す | `1 + 2` | `3` |
| `-` | 引く | `5 - 2` | `3` |
| `*` | 掛ける | `3 * 4` | `12` |
| `/` | 割る | `7 / 2` | `3.5` |
| `%` | 余り | `7 % 3` | `1` |

`/`は、割り切れなくても、小数で答えます。`+`は、文字列をつなぐこともできます。

```kururi
function main = () {
    print(7 / 2)
    print(7 % 3)
    print("くる" + "りん")
}
```

くるりんは、「3.5」「1」「くるりん」と話します。

## わざと間違える

式が、途中で終わっていたら、評価できません。

```kururi-error K0101
function main = () {
    print(3 * )
}
```

「ここには式が必要ですが、「)」がありました」と教えてくれます。`*`の右側に、値になるもの（式）が必要です。

## まとめ

- **式**は、評価すると**値**になるものです。
- 式は、内側から順に評価されます。`*`と`/`は、`+`と`-`より先です。
- `print`は、式を評価した値を、くるりんに話させます。

## 練習

1. 1個120円のりんごを3個と、50円のかごを買います。合計を、くるりんに話させてください。
2. `10 - 2 * 3`と`(10 - 2) * 3`の値を、実行する前に予想してください。
3. `17 / 5`と`17 % 5`は、どんな値になるでしょう。

<details>
<summary>答えの例</summary>

1つ目です。

```kururi
function main = () {
    print(120 * 3 + 50)
}
```

2つ目は、`10 - 2 * 3`が`4`、`(10 - 2) * 3`が`24`です。

```text
10 - 2 * 3
→ 10 - 6
→ 4
```

3つ目は、`17 / 5`が`3.4`、`17 % 5`が`2`です。

</details>
